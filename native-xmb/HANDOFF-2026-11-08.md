## 2. Build, run, verify

```powershell
# Build (exit 255 is normal; look for "Built")
$env:PATH="C:\Program Files (x86)\Microsoft Visual Studio\Installer;$env:PATH"
cd native-xmb; .\build.ps1 -OutputDirectory C:/dev/xmb/out/native-xmb
# Launcher: rebuilds when stale (-Build forces), uses out\native-xmb and ..\rpcs3\bin\dev_flash
.\run-native-xmb.ps1 -Build
# Appliance mode on the TV
re-ps3-native.exe --dev-flash <dev_flash> --data-dir <data> --kiosk --display 1
# Gates
bun work/ab-layers.ts --all --exe <exe>
.\work\release-check.ps1 -SkipBuild
```

Scripted runs: `--script "full,LEFT,DOWN,ENTER,wait,pause=ms,TRIANGLE,ESC,grab=<png>,quit"`, `XMB_LOG=<file>`.
Dry-run switches for live-system actions: `XMB_POWER_DRY_RUN=1`, `XMB_AUDIO_DRY_RUN=1`. The gate sets
`XMB_STEAM_ARTWORK=0` and `XMB_STEAM_ACTIVITY=0` so live Steam data never moves a capture. Named-state references
live in `out/native-reference/layers/` (untracked; backups `layers-backup-2026-11-0*`); re-save one with
`--state <name> --save-reference` only after an intended rendering change.

## 4. Configuration files (all in the data folder, `--data-dir`)

`spotify.json` (client id), `dlna.json`, `wol.json`, `homeassistant.json` (url + token; the token moves into a
DPAPI-sealed file on first start), `weather.json` (place, units), `apps.json` (imported apps, via `--import-apps`),
`profiles.json` (users, icons, autoLogin), `preferences.json`. Secrets are sealed with DPAPI for the Windows user;
nothing secret is logged or tracked.

## 6. Conventions

- Commit as `git -c user.name=Al -c user.email=ajgreenboy@gmail.com commit`, push to origin main. No AI attribution in
  commits, PRs or files.
- Commit only your own hunks when others have uncommitted work; prove a staged snapshot builds
  (`git checkout-index -a --prefix=<dir>/` then build it) and gate it before committing.
- Never commit firmware, extracted assets, captures, keys or account data; `dev_flash` stays outside the repository.
- Mark claims TRACED (cite module/address/RCO), measured, or INFERRED.
- Bun/TypeScript for helpers; no Python, no npm/npx.
- Test live-system actions (power, audio, network changes, deletes) with dry runs or scratch data only.
