# PS3 firmware fetch research

Sony's regional list is `https://dus01.ps3.update.playstation.net/update/ps3/list/<region>/ps3-updatelist.txt`, for example [us](https://dus01.ps3.update.playstation.net/update/ps3/list/us/ps3-updatelist.txt), [eu](https://dus01.ps3.update.playstation.net/update/ps3/list/eu/ps3-updatelist.txt), and [jp](https://dus01.ps3.update.playstation.net/update/ps3/list/jp/ps3-updatelist.txt). The US list observed on 2026-11-10 has semicolon-separated `Dest`, `ImageVersion`, `SystemSoftwareVersion=4.9300`, `CDN`, and `CDN_Timeout` fields. Separate rows describe an incremental `PS3PATCH.PUP` and the full `PS3UPDAT.PUP`; select the latter. The CDN is currently an **absolute HTTP URL**, not a relative path, though a relative URL can be resolved against the list URL. The pattern is `/update/ps3/image/<region>/<dated-build-id>/PS3UPDAT.PUP`. The fetcher upgrades Sony's HTTP link to HTTPS and does not ignore TLS errors; if Sony's endpoint does not offer valid HTTPS it fails rather than downloading unauthenticated bytes. [Sony's support page](https://www.playstation.com/en-us/support/hardware/ps3/system-software/) links the same HTTP PUP and specifies at least 200 MB free space (not an exact file size).

## Layout and extraction follow-up

The outer PUP has a header, entry table and hash table; entries are identified by IDs and carry offsets and lengths. See RPCS3 [`rpcs3/Loader/PUP.h`](https://github.com/RPCS3/rpcs3/blob/master/rpcs3/Loader/PUP.h) and [`PUP.cpp`](https://github.com/RPCS3/rpcs3/blob/master/rpcs3/Loader/PUP.cpp). It is not simply a sequence of encrypted files: RPCS3 validates the outer container and hashes, reads version entry `0x100`, then opens entry `0x300` as the `update_files` TAR. The TAR includes system packages such as CORE OS and `dev_flash_*`; the latter are signed/encrypted SCE packages, not plain outer PUP entries. RPCS3's [installer](https://github.com/RPCS3/rpcs3/blob/master/rpcs3/rpcs3qt/main_window.cpp) filters `dev_flash_` names, runs `SCEDecrypter` with `SCEPKG_ERK` and `SCEPKG_RIV`, then extracts the third resulting stream as a TAR into dev_flash. Publicly known PS3 keys are present in RPCS3's source, for example [`Crypto/key_vault.cpp`](https://github.com/RPCS3/rpcs3/blob/master/rpcs3/Crypto/key_vault.cpp); AES decryption and decompression/unpacking remain follow-up work. This fetcher does not validate PUP hashes, authenticate the PUP, decrypt, or extract it.

## Version and distribution

This build targets **4.93**. The US list inspected on 2026-11-10 advertised `4.9300` (4.93), consistent with Sony's support page. Inspection required a diagnostic request with certificate checks disabled because the endpoint's certificate failed hostname validation in this environment; this is not trusted verification and the app does not disable verification. Before installing, compare the normalized list version and the actual validated PUP's `0x100` version against 4.93, and reject or explicitly warn on mismatch; a list alone cannot verify downloaded content. The headless check only compares the advertised version.

RPCS3 supports installing Sony's official firmware supplied by the user; this feature likewise fetches Sony's own file for the user's machine. This is not legal advice: users should consider applicable law and Sony's terms. No firmware, keys, or secrets are committed to this public repository.
