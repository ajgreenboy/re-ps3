## 2. Build, run, verify

```powershell
# build (stop re-ps3-native.exe first; the linker fails while it runs)
& .\native-xmb\build.ps1                                   # -> out\native-xmb\re-ps3-native.exe
& .\native-xmb\build.ps1 -OutputDirectory C:\dev\out\scratch # side build, avoids clashing with another session

# run
& .\run-native-xmb.ps1                                      # or re-ps3-native.exe --dev-flash <dev_flash>
```

Useful flags: `--dev-flash`, `--data-dir`, `--background-clock <ISO>`, `--render-clock <s>` (freezes
animation for reproducible captures), `--ui-clock`, `--focus-time <ms>`, `--script "tokens"` (`size=WxH`,
`full`, `wait`, `DOWN/UP/LEFT/RIGHT`, `ENTER`, `grab=<png>`, `burst=`, `idle=<ms>`, `quit`).

Verification (the maintained gate — no new test suites without a request):

```powershell
# full gate: stored per-layer pair + canonical firmware capture + named Steam states
& "$env:USERPROFILE\.bun\bin\bun.exe" work\ab-layers.ts --all
# single-image scoring, whole frame or a crop
& "$env:USERPROFILE\.bun\bin\bun.exe" work\ab-compare.ts <ref.png> <native.png> [x,y,w,h]
```

State dumps for scripted assertions: `XMB_DUMP_ENTRIES=<file>` writes the rebuilt catalogue, and
`<file>.folder.json` / `<file>.store.json` when a folder or store page opens.

## 6. Ground rules and gotchas

- **Firmware and derived data never enter Git**: `fw493/`, `boot/`, `out/`, decrypted modules, RCO
  dumps, captures and probe media are gitignored. Only source, docs and approved screenshots are committed.
- **Steam Web API key** lives outside the repo at `%APPDATA%\re-ps3-native\steam_api_key` (one line) or
  `STEAM_WEB_API_KEY` in the environment. A `pre-push` hook blocks any push carrying it; never commit,
  log or paste it. Nothing is pushed without asking.
- **Builds**: stop a running `re-ps3-native.exe` before linking. Parallel sessions should use separate
  `-OutputDirectory` values.
- **Scripts**: Bun/TypeScript for tooling (`work/*.ts` is tracked, other `work/` output is ignored);
  PowerShell is fine for one-off commands. No Python without approval.
- **No new test suites** unless asked: `work/ab-layers.ts` and the `--script` captures are the maintained
  verification path.
- **RPCS3** can be driven locally for reference captures (`XMB_FP_DUMP`, `XMB_VTX_DUMP` hooks); firmware
  captures stay in `out/`.
- **Other agents share this tree**: run `git status` before editing, commit only your own files, and
  prefer separate build directories.
