## 2. Build, run, verify

```powershell
# Build (exit 255 is normal; look for "Built")
$env:PATH="C:\Program Files (x86)\Microsoft Visual Studio\Installer;$env:PATH"
cd native-xmb; .\build.ps1 -OutputDirectory C:/dev/xmb/out/native-xmb
# Launcher (repo root): builds and runs out\integration with ..\rpcs3\bin\dev_flash
..\run-native-xmb.ps1 -Build
# Appliance mode
re-ps3-native.exe --dev-flash <dev_flash> --data-dir <data> --kiosk --display 1
# Gates (run v2-fixtures once per machine before the first gate run)
bun work/v2-fixtures.ts
bun work/ab-layers.ts --all --exe <exe>
.\work\release-check.ps1 -SkipBuild
```

- **Build failures:** a failed build only prints "Native C++ build failed". To see the compiler errors, run
  `cmake --build <out>` inside `vcvars64.bat`; build.ps1 shows how it finds them with
  `vswhere -products '*'`.
- **Scripted runs:** `--script "full,LEFT,DOWN,ENTER,wait,pause=ms,TRIANGLE,ESC,guide,grab=<png>,quit"`, with
  `XMB_LOG=<file>` for the log.
- **Dry-run switches:** `XMB_POWER_DRY_RUN=1` and `XMB_AUDIO_DRY_RUN=1` for live-system actions.
  `XMB_AUTOSTART_TASK=<name>` gives a scratch task name for the Start at Sign-in row.
- **Single instance:** a second interactive launch hands `--show` / `--desktop` / `--quit` to the running XMB for
  the same `--data-dir`. Set `XMB_SINGLE_INSTANCE=0` for parallel test runs. `--script` and the report modes never
  take part.
- **Pinning for captures:**
  - `XMB_STEAM_ARTWORK=0` and `XMB_STEAM_ACTIVITY=0` keep live Steam data out of captures (the gate sets both).
  - `XMB_MUSICVIS_FIXED=1` and `XMB_GAMEBOOT_AT=<s>` pin the V2 scenarios.
- **The 22 states:** the 12 originals, plus 10 V2 scenarios (music Visual Player x3, Photo Gallery piles/grid, game
  boot x2, Auto-Off guide, in-game XMB over a stub window, RAF still).
- **References:**
  - They live in `out/native-reference/` (untracked).
  - `out/native-reference/v2/` holds the V2 seeds.
  - Re-save one with `--state <name> --save-reference` only after an intended rendering change, and back the
    folder up first.
- **Parallel gate runs collide.** They share `C:\dev\out\v2` (stub log, stub game window). An `EBUSY` on `stub.log`
  or a lone `ingame-xmb` frame failure during a parallel run is environmental; re-run that state alone with
  `--state ingame-xmb`.

2. `git cherry-pick wt/<n>` onto main. Expect small conflicts in `CMakeLists.txt` (the source list) and

3. Build main and check what the change can affect (the states it touches, run alone with `--state <name>`). A full

never `--save-reference`.

If an agent stops without reporting, its uncommitted work is still in its worktree. Check `git -C <worktree> status`
before removing it.

## 6. Conventions

- **Commits:**
  - Commit as `git -c user.name=Al -c user.email=ajgreenboy@gmail.com commit` and push to origin main.
  - No AI attribution in commits, PRs or files. No Co-Authored-By lines.
- **Shared tree:**
  - Other sessions commit to this repository too. Commit only your own hunks.
  - Prove that a staged snapshot builds (`git checkout-index -a --prefix=<dir>/`, then build it) and, where the change
    can alter a rendered state, that the affected states pass (`--state <name>`). The full gate is no longer run per
    change (decision 2026-11-11); keep it for rendering changes and releases.
- **What never goes in the repo:** firmware, extracted assets, captures, dumps, keys or account data. `dev_flash`
  stays outside the repository. The repo is public now.
- **Claims:** mark them TRACED (cite module/address/RCO), measured, or INFERRED.
- **Tooling:** Bun/TypeScript for helpers; no Python, no npm/npx.
- **Live-system actions** (power, audio, autostart task, shortcuts, network changes, deletes):
  - Test them only with dry runs, scratch names or scratch folders.
  - Never touch the real `re-ps3-native-kiosk` task or the real Start menu during development.
- **Processes:** never stop processes by name. Stop only PIDs your own test started. On 2026-11-09 a test agent
  broke this rule once.
- **Do not modify the user's RPCS3 data.** `Default.yml` must keep sha256
  `e624da0d66a8e971173c39a69a1dc2c89ffe146d57bf2a03c2c8cfacb459ceee`.
